# مستندات و راهنمای ساختار دارایی‌های برند حس خوب (Hessekhub Brand Assets)

این پوشه شامل تمامی فایل‌ها و دارایی‌های بصری برند **حس خوب (Hessekhub)** است که بر اساس کتابچه برند (Brandbook) و راهنمای سیستم دیزاین مرتب‌سازی، دسته‌بندی و استانداردسازی شده است.

---

## ۱. ساختار پوشه‌ها (Directory Structure)

```
Assets/
├── Brand-Glyphs/         # ۱۹ فرم و گلیف بصری برند (با نام‌گذاری معنادار و توکن رنگی)
├── Logos/                # نشان‌نوشته و لوگوی رسمی حس خوب (نسخه‌های تیره و روشن)
├── Brandbook/            # فایل‌های PDF دفترچه هویت برند (نسخه اصلی و فشرده)
├── _raw-export/          # آرشیو دست‌نخورده از خروجی‌های اولیه ایلاستریتور (PNG-03 تا PNG-21)
├── catalog.html          # کاتالوگ تعاملی و بصری دارایی‌ها برای مرور سریع
└── README.md             # مستندات و شناسنامه کامل دارایی‌ها
```

## ۴. اصول استفاده از گلیف‌ها در رابط کاربری و برند

1. **گلیف‌ها آیکون کاربردی UI نیستند:** از این فرم‌ها نباید به جای آیکون دکمه، منو یا فیلدهای فرم استفاده شود. آیکون‌های عملکردی سیستم به صورت خطی طراحی می‌شوند.
2. **نقش احساسی و پترن:** گلیف‌ها برای لحظات برجسته برند طراحی شده‌اند:
   - صفحه خوش‌آمدگویی و آنبوردینگ (Welcome Flow)
   - وضعیت‌های خالی (Empty States)
   - جشن دستیابی به اهداف (Celebration / Milestone)
   - الگوهای گرافیکی تکرارشونده روی بسته‌بندی، سوشال مدیا و کارت‌ها
3. **عدم دخل و تصرف بصری:** فرم‌ها نباید دفرمه شوند، زاویه چرخش آن‌ها باید با گام‌های ۱۵ درجه تنظیم گردد و گرادیان یا افکت سایه روی آن‌ها اعمال نشود.
